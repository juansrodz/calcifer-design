# DataGrid Release 1 (Grid core) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `DataGrid`'s core in `@calcifer-design/ui`: both data modes with sorting, a virtualised
keyboard-navigable grid, highlight, checkbox selection, row events, a row actions column and
expandable rows.

**Architecture:** A new `components/DataGrid/` folder. TanStack Table v9 (already a dependency) holds
columns, sorting, selection and expansion; TanStack Virtual renders only the visible rows of a native
`<table role="grid">` using spacer rows; a roving-focus hook owns keyboard navigation. Public types are
fixed in Task 1 so later tasks only fill them in. Later releases (filters, columns, saving, dragging)
add to these files.

**Tech Stack:** React 19, TypeScript, `@tanstack/react-table` ^9.2.4, `@tanstack/react-virtual` (new),
Base UI `Checkbox`, CSS Modules on `@calcifer-design/tokens`, Vitest + Testing Library + vitest-axe,
Storybook 10.

**Spec:** `docs/superpowers/specs/2026-11-04-data-grid-design.md`. Read it first. This plan covers its
release 1 only.

## Review Focus

1. **Rows replaced under the user.** A refresh or a new page set that drops the focused, highlighted or
   selected row: focus moves to the same position (clamped), the highlight clears, and the selection
   loses the missing ids with one `onSelectedRowIdsChange` call. Test in Task 6.
2. **A load that adds nothing.** In server mode `loadingMore` goes back to false with no new rows while
   `hasMore` is still true: `onLoadMore` must not fire again until the row count changes or the user
   retries. Test in Task 8.
3. **Clicks on controls inside cells.** A button or link in a cell or in the row actions column must not
   also count as a row click, highlight, or selection toggle. Test in Task 5.
4. **Sorting with expanded and selected rows.** In client mode a sort clears the selection (spec) but
   keeps expanded rows open by id, and the detail panels move with their rows. Test in Task 7.
5. **Right-to-left pages.** With the page direction set to `rtl` (by stylesheet, no `dir` attribute),
   ArrowLeft moves to the next column and ArrowRight to the previous one. Test in Task 4.
